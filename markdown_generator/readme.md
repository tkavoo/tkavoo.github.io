# Optional publication and presentation generators

These Python scripts are retained as reference utilities for generating Jekyll collection entries from structured records or BibTeX:

- `publications.py` reads a tab-separated publication file.
- `pubsFromBib.py` reads BibTeX data.
- `talks.py` reads a tab-separated presentation file.

The sample notebooks and placeholder datasets have been removed. The current website's publications and presentations pages are maintained directly in `_pages/`; the generators are not part of the site build. Their output format reflects the older collection-based site and may need adaptation before use.
